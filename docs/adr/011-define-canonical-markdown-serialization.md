# ADR-011: 正規化された Markdown シリアライズ規則を採用する

## ステータス

承認

## 背景

Markdown シリアライズでは AST の意味的等価性を保持する。

しかし、CommonMark では同じ意味を複数の記法で表現できるため、意味的等価性だけでは、シリアライザがどの記法を選択して出力するかは決まらない。

同一の AST から常に決定的な Markdown を生成し、シリアライザの実装およびテストを安定させるため、出力記法の選択方針を決定する必要がある。

## 決定

「意味を保持する固定の正規化記法を出力する」を採用する。

入力時の Markdown 記法を保持せず、同一の AST に対して一定の記法を選択して出力することで、シリアライザの出力を決定的にし、実装およびテストにおける期待値を固定できるため。

具体的な Markdown 記法の選択規則は、シリアライザの仕様として別途定義する。

## 検討案

### 記法選択を各シリアライザ実装に委ねる

AST の内容を意味的に保持することだけを要件とし、具体的な Markdown 記法の選択は各シリアライザの実装に委ねる方式。

- 利点: 実装時の自由度が高い。
- 欠点: 同一の AST から異なる Markdown が生成される可能性がある。
- 欠点: シリアライザの出力を一意にテストしにくい。

### 入力時の記法を AST に保存して再現する

Markdown の入力時に使用されていた記法情報を AST に保持し、シリアライズ時に可能な限り元の記法を再現する方式。

- 利点: 入力 Markdown の記法を保持しやすい。
- 利点: 入力と出力の表現上の差異を小さくできる。
- 欠点: AST に記法情報を保持する必要がある。
- 欠点: AST の構造や編集内容によって、元の記法を再現できない場合がある。

### 意味を保持する固定の正規化記法を出力する

AST の意味を保持しつつ、Markdown の記法をあらかじめ定めた規則に従って選択する方式。

- 利点: 同一の AST から常に決定的な Markdown を生成できる。
- 利点: シリアライザの出力を固定してテストできる。
- 欠点: 入力 Markdown の記法は保持されない。
- 欠点: 複数の Markdown 記法を正規化するための規則を定義する必要がある。
