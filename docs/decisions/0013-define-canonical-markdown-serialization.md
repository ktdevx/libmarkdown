# 正規化された Markdown シリアライズ規則を定義する

## Context and Problem Statement

意味的等価性だけでは、シリアライザが複数の CommonMark 記法からどれを選ぶか決まらない。実装・テストを独立にタスク分解するには、見出し、リスト、コードブロック、リンク、参照定義、改行およびエスケープについて決定的な出力規則が必要である。

## Considered Options

* 記法選択を各シリアライザ実装に委ねる
* 入力時の記法を AST に保存して再現する
* 意味を保持する固定の正規化記法を出力する

## Decision Outcome

Chosen option: "意味を保持する固定の正規化記法を出力する", because ソース保持を必要とせず、シリアライザの出力とテスト期待値を決定的にできるため。

シリアライザは LF 改行、ATX 見出し、`-` の bullet、連番付き ordered list、インライン形式のリンクおよび画像を使用する。コードブロックは内容と衝突しない最短の fence を選び、テキストは出力文脈で再解析時に構造を変える文字だけをエスケープする。参照定義は AST 上の位置で正規化して出力し、参照リンクは定義記法に戻さない。

### Consequences

* Good, because 同一 AST から常に同じ Markdown を生成できる。
* Good, because 記法に関するシリアライザ単体テストを固定できる。
* Bad, because 入力 Markdown の記法は保持されない。
* Bad, because 文脈依存エスケープと fence 選択を実装する必要がある。
